# Data Schema

Single source of truth: Supabase (PostgreSQL) via the Session-mode connection pooler. Schema is
managed by Alembic (`platform/backend/alembic/`); never edit an already-applied migration —
schema changes are new migrations. Models live in `platform/backend/db/models/`.

Below: tables as defined in the actual SQLAlchemy models (columns simplified — see each file for
full types/defaults/indexes).

## Risk & prediction

**`risk_predictions`** (`risk_prediction.py`)
`id` (PK), `commune_id` (indexed), `risk_score` (float), `risk_category` (str), `model_version`,
`explanation` (text), `raw_output` (JSONB — carries `n_eventos`, `derivation`, `conflicts`,
`priority`, `confidence`), `created_at`.

**`risk_explanations`** (`risk_explanation.py`)
`id` (PK), `commune_id`, `risk_score`, `risk_category`, `explanation` (text),
`explanation_json` (JSONB), `generated_by` (default `"template"`), `generated_at`.

**`ml_features`** (`ml_feature.py`)
`id` (PK), `commune_id` (indexed), `reference_date`, `features` (JSONB — free-form feature bag,
e.g. `precip_sum_mm_day`, `mean_precip_mm_snapshot`, `source`), `precip_acum_7d` (float, **not
populated by any scraper** — do not read it), `n_events_window`, `created_at`.

## Events & hazard

**`landslide_events`** (`landslide_event.py`)
`id` (PK), `source_row_id` (dedupe key), `fecha` (free text, multiple formats), `tipo_emergencia`,
`commune_id` (indexed, nullable), `barrio`, `latitud`/`longitud`, `has_coords`, `is_synthetic`
(bool — 144 rows generated by `scraper/ingest_synthetic_events.py`, **excluded from classifier
training** to avoid circular contamination with the Snake Line heuristic), `ingested_at`.

**`barrio_hazard`** (`barrio_hazard.py`)
`barrio_codigo` (PK), `nombre`, `commune_id` (indexed), `hazard_grade`, `updated_at`. Official
geomorphological hazard grade (~401 barrio polygons), populated by a one-off script
(`scraper/barrio_hazard.py`).

**`barrio_terrain`** (`barrio_terrain.py`)
`barrio_codigo` (PK), `commune_id`, `slope_mean_deg`/`slope_p90_deg`, `twi_mean`/`twi_p90`,
`ndvi_mean`/`ndvi_min`, `elevation_mean_m`, `dem_source`, `ndvi_source`, `updated_at`. Terrain
covariates behind the susceptibility index.

**`mesh_quadrants`** (`mesh_quadrant.py`)
`id` (PK, e.g. `"Q_0045"`), `geometry` (JSONB GeoJSON polygon), `commune_ids` (JSONB list),
`barrio_codigos` (JSONB list), `hazard_grade`, `n_barrios_alta`, `slope_p90_deg`, `twi_p90`,
`ndvi_mean`, `susceptibility_index`, `susceptibility_grade`, `updated_at`. ~1.5km JMA-style grid;
risk on this table is inherited from the commune, not per-cell.

## Rainfall & seismic

**`rainfall_timeseries`** (`rainfall_timeseries.py`)
`id` (PK), `commune_id`, `snapshot_at`, `precip_mm` (float), `station_count`,
`source` (default `"siata"`). SIATA snapshots roughly every 30 min — the table the dashboard's
live-rain and daily aggregations actually read.

**`daily_precipitation`** (`daily_precipitation.py`)
Composite PK (`commune_id`, `day`, `source`), `precip_mm`, `ingested_at`.

**`rainfall_forecast`** (`rainfall_forecast.py`)
`id` (PK), `commune_id`, `target_date`, `issued_at`, `horizon_days`, `precip_mm`, `precip_prob`,
`source`, `ingested_at`.

**`seismic_events`** (`seismic_event.py`)
`id` (PK), `source_row_id` (unique, dedupe), `source`, `station_code`/`station_name`,
`event_local_at`, `magnitude`, `mag_type`, `depth_km`, `epicenter_lat`/`epicenter_lon`,
`epicenter_label`, `cluster_id` (FK-like link), `ingested_at`. Same earthquake recorded by
multiple stations — deduplicated at query time by `(event_local_at, epicenter_label)`.

**`seismic_event_clusters`** (`seismic_event_cluster.py`)
`id` (PK), `event_at`, `magnitude`, `mag_type`, `depth_km`, `epicenter_lat`/`epicenter_lon`,
`epicenter_label`, `canonical_source`, `sources` (JSONB list), `source_count`, `member_count`,
`first_seen_at`, `updated_at`. Cross-source (SGC/USGS/SIMMA-style) dedup of `seismic_events`.

## Alerts & operational config

**`alert_log`** (`alert_log.py`)
`id` (PK), `commune_id` (indexed), `triggered_at`, `precip_acum_mm`, `threshold_mm`, `risk_score`,
`risk_category`, `webhook_url`, `status` (`sent`/`failed`/`cooldown`), `response_code`,
`created_at`.

**`commune_thresholds`** (`commune_threshold.py`)
`commune_id` (PK), `threshold_mm` (default 35.0), `updated_at`. Per-commune daily rain threshold
used by both the Slack alert pipeline and the composite alert-state endpoint.

**`app_settings`** (`app_setting.py`)
`key` (PK), `value` (text), `updated_at`. Generic KV store — e.g. `slack_webhook_url`.

**`safe_zones`** (`safe_zone.py`)
`id` (PK, e.g. `"osm_way_12345"`), `nombre`, `tipo` (`park`/`school`/`stadium`), `lat`/`lon`,
`validated` (bool, default false), `updated_at`. Candidate evacuation zones from OpenStreetMap.

**`citizen_reports`** (`citizen_report.py`)
`id` (PK), `commune_id` (indexed), `barrio`, `descripcion`, `status` (default
`"pending_review"`, indexed), `session_id`, `latitud`/`longitud`, `created_at`, `reviewed_at`.

## Operations / audit

**`scraping_logs`** (`scraping_log.py`)
`id` (PK), `source`, `status`, `run_started_at`/`run_finished_at`, `records_downloaded`,
`records_valid`, `records_discarded`, `detail`, `created_at`. `records_valid=0` with an `ok`
status means "no new events", not an error — scrapers dedupe by `source_row_id`.

**`audit_log`** (`audit_log.py`)
`id` (PK), `actor`, `action` (indexed), `resource`, `payload_hash` (SHA-256, never the raw
payload), `summary`, `created_at`. Append-only, written by `api/audit.py::log_audit_event` for
every token-gated mutating call.

**`agent_run_logs`** (`agent_run_log.py`)
`id` (PK), `agent_name`, `status`, `run_started_at`/`run_finished_at`, `summary`, `detail` (JSON),
`created_at`. Results of the `monitoring/` agents (`api_health`, `ml_drift`, `scraper_validator`,
`migration_guard`).

**`agent_conversations`** (`conversation.py`)
`id` (PK), `session_id` (indexed), `role`, `content`, `created_at`. Backs both `POST /api/chat`
and the derived `GET /api/chat/sessions` / `GET /api/chat/history/{id}` endpoints — no separate
sessions table.
